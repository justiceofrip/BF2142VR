# Upstream provenance

This repository contains the BF2142 adaptation of BFVR, originally developed by JayBiggsGMG and the BFVR contributors.

- Upstream: https://github.com/JayBiggsGMG/BFVR-Battlefield-1942-VR-Mod
- Base commit: `fe1ebc3ba42166c98e42dd217deac8f763e9c256`
- Base release context: BFVR v1.0.2.
- License: MIT, retained without removing the original copyright notice.

This is a clean source snapshot of the working BF2142 port, including its modifications to shared presenter/OpenXR code. It is not a GitHub network fork and does not reproduce upstream Git history. The base commit identifies the upstream starting point for comparison.

BF1942 targets and historical documentation remain available for reference. The root README, BUILD_BF2142.md, current BF2142 handoff and package controls describe this port; older BF1942 launch/install instructions describe the upstream game only.

# BF2142 VR sharing

**[Player download and installation instructions](https://github.com/justiceofrip/BF2142VR/releases/tag/v0.1.0-alpha.1)**

The 0.1.0-alpha.1 early playtest is public, with the player ZIP, checksums,
INSTALL.txt, validation report and a source ZIP. Installer, rollback and asset
checks pass. The owner explicitly approved publication with the final packaged
live-game/headset check still pending. Keep that validation limitation visible.

Share the release page above with players. Share the source repository or source
ZIP with contributors; BUILD_BF2142.md and BF2_PORTING.md are the starting points.
The player package installs without GitHub sign-in or developer tools.

Never share an installed BF2142VR folder. It contains reconstructed game artwork,
backups, local paths and logs. The original public ZIP generates those assets
from each player's own stock v1.51 game. START HERE.txt covers setup, requirements,
launch and uninstall. Preserve upstream credit and licenses.

The short Flat2VR post in BF2142_ANNOUNCEMENT.md can accompany a gameplay clip.
Initial scope is Quest/SteamVR singleplayer/bots. Online compatibility, remote
waving and Remaster remain unverified. Planned work includes multiplayer hit
registration, community Titan sessions, networked IK, physical vehicle controls
and optional manual reloads.

Feedback: version, headset/runtime, GPU, map/mod, failed action and a short clip.
Review logs before sharing personal paths or account information. Do not post
credentials, backups, generated artwork or install.json.

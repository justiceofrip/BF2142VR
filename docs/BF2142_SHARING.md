# BF2142 VR sharing

A 0.1.0-alpha.1 playtest ZIP based on v30 has been staged, with a SHA-256 sidecar
and validation report. Installer, rollback and asset checks pass. The final
packaged live-game/headset run is pending; nothing has been uploaded publicly.

Share the original ZIP after the release checklist is complete. Never share the
installed BF2142VR folder, which contains reconstructed game artwork, backups,
local paths and logs. The public package generates those from each player's own
stock v1.51 game. START HERE.txt covers setup, requirements, launch and uninstall.

GitHub is optional for installation. For public hosting, use one stable download
page, preferably a GitHub pre-release named BF2142 VR 0.1.0-alpha.1, with the ZIP,
checksum, known issues and instructions. Preserve upstream credit and licenses.
The source repository is prepared for justiceofrip/BF2142VR. Publishing source
does not publish the player candidate or assert its final headset acceptance.

The Flat2VR announcement can accompany a short gameplay clip and the eventual
download link. Initial scope is the tested Quest/SteamVR singleplayer/bot setup.
Online compatibility and remote waving remain unverified. Further work includes
multiplayer hit registration, community Titan sessions, networked IK, physical
vehicle controls and optional manual reloads.

Feedback: version, headset/runtime, GPU, map/mod, failed action and a short clip.
Review logs before sharing personal paths or account information. Do not post
credentials, backups, generated artwork or install.json.

For developers, share the source repository or clean source ZIP. See BUILD_BF2142.md and BF2_PORTING.md. Source downloads are not the compiled player mod.

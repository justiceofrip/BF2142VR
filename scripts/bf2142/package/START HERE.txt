BATTLEFIELD 2142 VR 0.2.0-beta.4

Requires your own working BF2142 v1.51 + Reclamation installation on Windows x64.
Reclamation setup and multiplayer: https://battlefield2142.co/
Confirm the normal game works first. VR includes the remote IK receiver;
VR players do not also install the flat addon. Custom weapon packs unsupported.

QUICK START
1. Open BF2142VRSetup.exe, choose your BF2142.exe, click Install / Update.
2. Connect the headset and start your OpenXR runtime (for example SteamVR).
3. Open the Battlefield 2142 VR shortcut and click Play VR.

Use that same launcher for Check for updates or Repair. Check verifies the
signed release and hashes of installed mod files, not just its version label.
Close the game before installing. Settings and original backups are preserved;
do not restore stock files or uninstall before each normal update.
No separate Python or .NET installation is required.

OFFLINE ZIP
Extract the complete ZIP to a new folder. Run Setup.cmd and select BF2142.exe.
The installed launcher and desktop shortcut offer Play VR and later updates.
Installed Play VR.cmd remains a direct launch option.

IF SETUP FAILS
Keep the backups and installation folder. Retry Install / Update; verified
weapon repairs are reused. Save error report in the launcher, review the text,
then use Report on GitHub and attach it. Nothing uploads automatically.
Do not share game archives, account files, generated models or WeaponCache.

Uninstall.cmd restores recorded original files and retains settings/backups.
If another mod changed a file, setup/uninstall stops to preserve it.

Read CONTROLS.txt and TROUBLESHOOTING.txt for controls, VR and multiplayer.
The separate flat/community helper uses its own runtime. Custom gestures and
voice require the matching server adapter/bridge; ordinary servers are in-game.
This launcher does not download Battlefield, Reclamation or extra maps.

BATTLEFIELD 2142 VR 0.2.0-beta.1

Requires your own working stock BF2142 v1.51 on Windows x64.
Set up Reclamation/OpenSpy separately and confirm you can log in.
VR already includes the remote IK receiver. Do not also install the flat addon.
Remaster/other weapon packs are not supported by this installer.

INSTALL / UPDATE
1. Close BF2142. Updating alpha? Run its installed Uninstall.cmd first.
   Rename that game's BF2142VR folder to preserve backups/settings.
   Do not overwrite the old installer folder with this ZIP.
2. Extract the entire beta ZIP into a new folder.
3. Run Setup.cmd, select BF2142.exe, and wait for local weapon/body/lobby setup.
   Original files are backed up for rollback. No game content is downloaded.
4. Connect through Steam Link/SteamVR. Use Battlefield 2142 VR Beta on the
   desktop or installed Play VR.cmd for singleplayer/bot matches.

COMMUNITY MULTIPLAYER
Use Join Community Server.cmd from this extracted ZIP. Choose Play in VR and
log in with your own Reclamation/OpenSpy account. Leave the helper running.
It verifies/downloads the community payload and joins the temporary test server.
If direct join stalls after login: IP 18.190.153.177, port 17567.
The server may be offline. Ordinary game/Hub shortcuts do not activate this mod.
Other community hosts need the VR server adapter and bridge too.

CONTROLS
Right-stick click recenters. B opens the game menu; VR CONTROLS opens settings.
Read CONTROLS.txt for body slots, aiming, vehicles and menus.
Voice worked with the second vrtester client; wider device testing remains.

ROLLBACK
Close the game and run installed Uninstall.cmd. It restores only recorded VR
changes and retains settings/verified backups. If another mod changed a file,
uninstall stops to protect it. Move the uninstalled folder aside before using
the earlier installer. Keep your old ZIP for rollback.
Community caches live separately under LOCALAPPDATA/BF2142VR/Community.
Older signed server revisions are rejected; authorized rollback requires a
new signed descriptor selecting an earlier payload.

Desktop Preview.cmd is optional synthetic tracking, not VR.
Latest arm/haptic fixes have automated coverage, not final headset acceptance.
See RELEASE NOTES.txt and the release CHECKS.txt.

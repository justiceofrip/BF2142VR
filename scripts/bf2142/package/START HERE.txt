BATTLEFIELD 2142 VR 0.2.0-beta.4-test.8 - EXPERIMENTAL TEST BUILD

Requires your own working stock BF2142 v1.51 on Windows x64.
Set up Reclamation/OpenSpy separately and confirm you can log in.
VR already includes the remote IK receiver. Do not also install the flat addon.
Remaster/other weapon packs are not supported by this installer.

INSTALL / UPDATE
Recommended: download BF2142VRSetup.exe from this release, open it, choose
BF2142.exe once, and click Install / Update. Keep the BF2142 VR Installer
shortcut for later updates. Repair checks/downloads damaged mod files and
rebuilds locally generated assets. No separate Python or .NET install needed.

The updater checks a signed preview-channel feed. It downloads changed mod
files only, preserves VR settings and original backups, and keeps the previous
runtime alongside the game. Close BF2142 before updating. It does not install
or download Battlefield itself, Reclamation, maps, or account information.

Offline alternative: extract the entire ZIP to a new folder, close BF2142,
run Setup.cmd and select BF2142.exe. Updating a healthy existing VR installation
no longer requires a manual uninstall. Do not overwrite an old extracted ZIP.
If the old install metadata/backups are damaged or another mod changed game
files, setup stops and retains them rather than guessing what to overwrite.

Weapon repairs are isolated and verified. Completed repairs are cached locally
so an interrupted attempt can resume. A failing weapon is retried once; setup
never silently skips it. Previous releases remain available on GitHub.

Connect your headset through SteamVR, then use Play VR or the game shortcut.

COMMUNITY MULTIPLAYER
This hotfix updates the installed Play VR runtime. The separate community
join helper/flat addon remains at beta.1 and selects its own signed runtime.
Use the previous community download for that path; this ZIP does not bundle it.
Normal servers can be selected in-game; custom gestures/voice need the matching
server adapter and bridge. The community test server may be offline.

CONTROLS
Look directly at your left wrist for 0.4 seconds, then point/click the small
DEPLOY button with the right controller
to open spawn/loadout. Right-stick click recenters. B opens the game menu;
VR CONTROLS opens settings.
Read CONTROLS.txt for body slots, aiming, vehicles and menus.
Voice worked with the second vrtester client; wider device testing remains.

ROLLBACK
Close the game and run installed Uninstall.cmd. It restores only recorded VR
changes and retains settings/verified backups. If another mod changed a file,
uninstall stops to protect it. Move the uninstalled folder aside before using
the earlier installer. Keep your old ZIP for rollback.
Community caches live separately under LOCALAPPDATA/BF2142VR/Community.
Older signed server revisions are rejected; authorized rollback requires a
new signed descriptor selecting an earlier payload.

Desktop Preview.cmd is optional synthetic tracking, not VR.
Latest arm/haptic fixes have automated coverage, not final headset acceptance.
See RELEASE NOTES.txt and the release CHECKS.txt.

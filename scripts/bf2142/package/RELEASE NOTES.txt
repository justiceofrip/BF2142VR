BF2142 VR 0.2.0-beta.4-test.6 - Installer and updater

New BF2142VRSetup.exe: folder picker, Install / Update, Repair, progress, logs
and Play VR. Signed update feed, verified downloads and a content cache fetch
only missing/changed mod files. Updates preserve VR settings and first-install
stock backups. The previous runtime is retained; interrupted swaps recover.
Game must be closed before updating. Original game files are never downloaded.

Bundled setup runtime updated from Python 3.12.0 to 3.13.15. Weapon coverage
queries use iterative traversal. Each weapon repair runs in a fresh worker;
accepted model hashes are checked before caching, and the full archive must
still match the accepted build. Failed repairs retry once, then stop with logs.
Completed verified repairs survive a later retry. No repeated full-setup loop.

All gameplay binaries are identical to test.5: draw timing, crate behavior,
fire modes, menus, IK and network protocols are unchanged. This is an installer
update, not another gameplay/visual hotfix. The reported machine's intermittent
native crash has not been reproduced locally; reporter confirmation is needed.

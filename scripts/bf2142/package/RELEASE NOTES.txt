BF2142 VR 0.2.0-beta.3 - Ladder/input hotfix

- Fix ladder attachment blocked by an invisible downward native look angle.
- Held grips no longer cancel deliberate ladder thumbstick movement.
- Snap turning now uses the game's stock network input; no custom snap event.
- Includes beta.2: 1600x900 source, actual native MSAA, accessible menu Exit,
  and persistent installer errors/logs.

Use your own BF2142 v1.51 installation. Close the game before setup.
Updating: run the old installed Uninstall.cmd, move its BF2142VR folder aside
with backups intact, then run this package's Setup.cmd. Do not merge ZIPs.
The separate community helper and flat addon remain at beta.1.

Ladder ascent was confirmed in desktop VR simulation. Both native builds and
71 tests pass; this is not new headset or remote-server ladder acceptance.
Installer failures reported on another PC remain under investigation. If setup
fails, retain the log from LocalAppData/BF2142VR/SetupLogs. A successful local
install does not establish that the reported intermittent failure is solved.
Experimental optics, weapon grip changes and texture upscaling are not included.
Crosshair VISIBLE still means the native flat HUD; leave it hidden in VR.
